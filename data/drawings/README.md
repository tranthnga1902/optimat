# Bản vẽ

- `build/`: bản vẽ dùng để chỉnh quy tắc và ngưỡng nhận diện (đang có nhà phố, nhà dân, kết cấu do người dùng cung cấp).
- `test/`: bản vẽ chỉ dùng để báo cáo sai số, không xem khi chỉnh quy tắc.

File `.dxf`, `.dwg` không đưa vào git (lớn). Xem trang kiểm tra: `python scripts/view_takeoff.py data/drawings/build/nha_pho.dxf --open`.
